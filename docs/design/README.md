# Product design (intent, not spec)

This folder holds the product side of the game: names and art direction, the 100-level plan, feel, player-facing copy, and ideas that aren't scheduled. It was put together on 28 Oct 2026 from product's proposals (`docs/proposals/levels.md`, `mechanics.md`, `screens.md`) after the developer review.

- **Not a spec.** Nothing here is implemented or required unless it also appears in CLAUDE.md or `docs/*.md`. Where they disagree, the dev specs win until the team agrees otherwise.
- **Not read by default.** Read a file here only when a task needs product intent: level curation, step 6 feel, copy, art.
- **Terms:** code names (tube, ball, veil, lock, clay, large tube). Art names are mapped once, in names-and-art.md.
- **Open issue** notes mark inconsistencies the review found; product resolves them.
- Paths such as `prototype/potion-sort-lab.html`, `tools/levelgen/` or `docs/art/…` are in the product repo, not in this one.
- Other games and third-party characters are not named here: this repository ships to reviewers.

| File | Holds |
|---|---|
| names-and-art.md | Art names → code names, how each mechanic looks, palettes, creatures, UI kit |
| level-plan.md | Episodes, tiers, mechanic unlocks and how each is used, board look, difficulty, the prototype generator, the 100-level table |
| feel.md | Motion, effects, win sequence, sound, haptics |
| copy.md | Player-facing text: tutorials, tags, popups |
| meta-ideas.md | Proposed but unscheduled: lives, level variants, booster buying, shop, leaderboard, ads, episode overlay, win grades, screen changes |
| decisions.md | Product decision ids, product status, pending team decisions |
